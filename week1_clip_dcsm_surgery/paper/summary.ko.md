# 논문 초안 해설

영문 초안: [From Dense CLIP Maps to Object Selection: A COCO Study of Localization and Compositional Transfer](manuscript.md)

이 논문의 핵심은 **CLIP에서 물체 위치가 더 선명하게 드러나는 것과, 문장에 맞는 물체를 선택하는 것은 별도로 평가해야 한다**는 관찰입니다. 기존 실험 결과로 초록, 서론, 관련 연구, 방법, 결과, 한계, 결론과 부록을 작성했습니다. 새로운 모델 추론은 실행하지 않았으며, 저장된 문항별 예측에 대한 통계 분석과 그림 작성을 추가했습니다.

## 1. 무엇을 비교한 연구인가

첫째, 같은 CLIP ViT-B/16에서 마지막 블록의 특징을 세 방식으로 읽었습니다. 기본 특징인 `naive`, value 특징을 사용하는 MaskCLIP 방식, query–query attention을 사용하는 ClearCLIP 방식입니다. 뒤의 두 방식은 기존 연구를 적용한 것으로, 이번 연구가 새로 제안한 알고리즘은 아닙니다.

둘째, 텍스트 전체를 요약한 EOS 임베딩과 토큰별 유사도의 최댓값을 비교했습니다. 코드의 `dcsm_tok`는 토큰 유사도를 최댓값으로 줄이는 방식입니다. **원 논문의 학습된 DCSM CNN과 동일한 방법이 아닙니다.** 학습된 DCSM은 별도의 비교군으로, 공개된 두 체크포인트를 사용했습니다.

셋째, 평가를 세 단계로 나눴습니다. 물체 종류를 알려준 상태의 위치 탐색, COCO 검출, 그리고 같은 종류의 후보 물체 중 문장에 맞는 하나를 고르는 평가입니다. 마지막 평가에는 정답 후보 박스가 제공되므로, 이미지 전체에서 후보까지 찾아내는 referring detection 성능으로 해석할 수 없습니다.

## 2. 실제로 확인된 결과

| 질문 | 확인된 수치 | 해석 |
| --- | --- | --- |
| 물체 종류의 위치를 더 잘 찾는가? | 224 입력의 위치 지목 정확도: 기본 EOS 12.0% → ClearCLIP 방식 EOS 62.4% | 알려진 종류의 물체 영역을 찾는 신호가 개선됨 |
| 제안된 박스를 활용하면 검출이 개선되는가? | 같은 P2 규칙에서 AP 2.6 → 27.3 | 특징 읽기 방식이 해당 검출 파이프라인에 큰 영향을 줌 |
| 히트맵만으로 좋은 검출기가 되는가? | P1 최고 AP는 반올림 기준 4.6 | 단순 연결 요소로 박스를 만드는 방식에는 한계가 있음 |
| 더 선명한 특징이 공간 관계 선택도 개선하는가? | ClearCLIP 방식 EOS 39.4%, 기본 EOS 50.3%의 보정 정확도 | 이 평균 집계 방식에서는 개선이 일관되게 전이되지 않음 |
| 학습된 DCSM은 공간 관계에서 도움이 되는가? | ObjA 58.1%, COCO 57.3%; 보정 기준 확률 45.7% | 현재 문항 집합에서 공간 관계 선택의 이점이 관찰됨 |

검출은 비군중 객체가 있는 **4,952장**에서 평가했습니다. AP는 0–100 단위이며, 정확도와 다른 지표입니다. OWLv2 기본 검출기의 AP는 46.8입니다. 다만 OWLv2 기본 평가와 P2는 제안 박스 선택과 점수 계산이 다르므로, 46.8과 27.3의 차이를 순수한 분류 능력 차이로 단정하지 않았습니다.

공간 관계 문항은 375장의 이미지에서 나온 527개입니다. 같은 이미지의 문항을 함께 재표집하는 부트스트랩을 10,000회 수행했습니다. DCSM ObjA의 보정 정확도는 **58.1%, 탐색적 95% 구간 [53.7, 62.4]%**입니다. 기준 확률 대비 차이는 **+12.4%p, 구간 [+8.0, +16.7]%p**입니다. 이 구간은 현재 자동 생성 문항의 표본 변동을 나타내며, 라벨 오류나 학습 데이터 중복까지 반영하지 않습니다.

## 3. 원시 정확도를 그대로 쓰면 생기는 문제

크기 문항 655개 중 큰 물체를 묻는 문항은 575개, 작은 물체를 묻는 문항은 80개입니다. 문장을 읽지 않고 가장 큰 박스만 골라도 원시 정확도 87.3%를 얻습니다. OWLv2의 크기 정확도 역시 원시 64.7%에서 큰/작은 문항에 같은 비중을 주면 41.7%로 바뀝니다. 따라서 원시 수치만으로 크기 표현을 이해했다고 주장하기 어렵습니다.

크기 문항의 정답은 COCO의 객체 annotation area로 결정하지만, 크기 휴리스틱은 bounding-box area를 사용합니다. 두 면적은 동일하지 않아서 보정한 휴리스틱 값이 항상 정확히 50%가 되는 것도 아닙니다. 본문의 보정은 특정 크기 편향을 줄일 뿐, 물체 종류·배치·후보 수에 따른 편향을 모두 없애지는 않습니다.

## 4. 부정 표현에 대해서는 어떤 주장이 가능한가

`without` 문항에서 학습된 DCSM의 보정 정확도는 38.7%와 37.5%로 기준 확률 48.1%보다 낮습니다. 그러나 기본 토큰 최댓값 방식은 55.7%, CLIP 후보 crop은 53.0%입니다. 따라서 “모든 방법이 부정을 전혀 이해하지 못한다”는 결론은 이 결과와 맞지 않습니다. 기준 확률을 넘었다는 사실만으로 의미 이해를 입증하는 것도 아닙니다.

문항 생성 코드에도 중요한 차이가 있습니다. 두 후보 중 하나만 B를 가지는 장면은 `with`와 `without` 조건을 동시에 만족하지만, 생성기는 허용되는 경우 `without`을 먼저 선택합니다. 실제 두 후보 문항은 `without`에서 273/315개, `with`에서 44/194개입니다. 두 집합은 같은 장면에서 단어만 바꾼 대조군이 아닙니다. 따라서 결과 차이를 부정 단어 하나의 효과로 해석하지 않았습니다.

## 5. 논문에서 주장한 범위와 남은 작업

현재 근거가 지지하는 주장은 **평가한 파이프라인에서 위치·검출 개선이 관계 선택 개선으로 일관되게 이어지지는 않았고, 공개 DCSM scorer는 공간 관계 문항에서 이점을 보였다**는 것입니다. 수정된 특징에 학습된 DCSM scorer를 결합한 실험은 수행하지 않았습니다. 따라서 “ClearCLIP을 DCSM CNN에 넣으면 성능이 나빠진다”는 주장도 하지 않았습니다.

투고 전에는 자동 생성 라벨의 사람 검증, 같은 장면을 사용하는 긍정·부정 쌍, readout과 학습 scorer를 조합한 통제 실험, 공개 체크포인트의 학습 데이터 중복 확인, 독립 데이터셋 평가, 선행 연구 대비 신규성 검토가 필요합니다. 저자·소속·투고처도 아직 지정되지 않았습니다. 이러한 미확인 사항을 감추지 않고 [내부 검토 메모](review_notes.md)에 정리했습니다.
