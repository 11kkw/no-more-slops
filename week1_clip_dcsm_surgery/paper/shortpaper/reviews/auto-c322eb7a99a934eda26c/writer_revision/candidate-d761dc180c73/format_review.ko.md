## 1. 판정 요약

- **기존 `../manuscript.md`: 학술 논문 구성을 갖춘 장문 작업 초안. 본문 4쪽·2단 숏페이퍼 형식으로 확인된 원고는 아님.**
- **새 `shortpaper.pdf`: 본문 4쪽·2단, 참고문헌 별도 1쪽, 전체 5쪽으로 실제 컴파일·확인한 숏페이퍼 작업본.**
- 특정 학회 공식 템플릿 준수·투고 준비 완료·신규성 검증·독립 동료심사 완료 판정은 하지 않는다.
- 형식 검사 결과는 **경미한 조판 경고를 명시한 통과(`passed_with_warnings`)**다. 실제 PDF의 가로 넘침·내용 겹침·절단은 발견하지 않았다.

## 2. 기존 파일 직접 검토

검토 대상은 `../manuscript.md`이며, 제목/초록/서론/관련 연구/방법/결과/논의와 한계/결론/사사/부록 A–B/Sources를 실제 헤딩으로 확인했다. 방법에는 readout, 평가 프로토콜, 문항 생성, 후보 scorer, 지표와 불확실성이 있다. 결과에는 위치·검출·크기 지름길·공간 선택·attachment 진단이 있다. **학술 논문 내용 구성은 충족**한다.

그러나 이 파일 자체는 Markdown이다. `\documentclass`, 용지 크기, 여백, 두 단의 조판 설정, 컴파일된 본문 페이지 수를 갖춘 LaTeX/PDF가 아니므로, 섹션이 있다고 해서 4쪽·2단 논문이라고 판정하지 않았다. 이 작업에서는 원본 전체를 억지로 4쪽에 넣지 않고, 공간 관계 전이 관찰을 중심으로 별도 숏페이퍼를 썼다. 원본의 상세 후보 표·부록은 보충 자료로 연결했다.

원본 보존 근거: 작성 전 프로젝트 파일 해시 스냅샷과 작성 후 비교에서 **114개 기존 파일 변경 없음**. `input_snapshot.json`, `build_validation.json`의 `existing_project_inputs_preserved` 검사 참조. 새 `shortpaper/` 및 `__pycache__`는 스냅샷 비교 범위에서 제외했다. 원본 manuscript SHA256: `f7bad850593e4dbcc3ceb5e5fec96456acd7986ef97f269093597b68359bfc5e`.

## 3. 새 원고의 실제 조판 설정

| 항목 | 실제 설정/확인 |
| --- | --- |
| 문서 클래스 | `article`, `10pt`, `twocolumn`, `letterpaper` |

| 표/캡션 | 본문과 같은 10pt, booktabs 표 2개 |

참고문헌은 문서의 두 단 설정을 유지하지만, 8개 문헌이 왼쪽 단에 모두 들어가 오른쪽 단이 비어 있다. 이는 별도 참고문헌 1쪽이며 본문 4쪽 계산에 넣지 않았다.

## 4. 실제 페이지와 시각 검사

PyMuPDF로 실제 PDF를 열어 **총 5쪽**을 확인했다. 본문 종료 LaTeX label의 aux 기록은 4쪽이고, PDF 텍스트의 `References` 시작은 5쪽이다. 각 본문 페이지에 왼쪽과 오른쪽 단의 본문 줄이 모두 존재한다.

- **1쪽:** 제목, 저자 미정 표기, 완전한 초록, 서론·관련 연구, 방법 시작. 초록의 모든 성능 수치와 마지막 범위 제한 문장까지 표시됨.
- **2쪽:** readout 수식, 위치/검출 프로토콜, 조건부 후보 선택, 균형 지표와 불확실성. 긴 모델 ID가 단을 넘어가지 않음.
- **3쪽:** 핵심 표 2개, 공간 관계 오차막대 그림 1개, 결과. 표 숫자와 캡션을 읽을 수 있고 그림은 색 없이 구분 가능.
- **4쪽:** 생성 편향 진단, 논의와 한계, 결론, 사사/근거 위치. 마지막 페이지 두 단을 균등 배치해 결론의 부자연스러운 단 경계를 줄임. 하단 자연 여백을 인위적으로 채우지 않음.
- **5쪽:** 참고문헌 8개. 깨진 인용키나 누락 문헌을 발견하지 않음.

`renders/page-1.png`–`page-5.png`를 실제 PDF에서 렌더링해 Hermes의 native vision으로 확인했다. 마지막 균등 배치 변경 후 4쪽 렌더를 다시 확인했다. 이 검사는 독립 인간 심사가 아니다.

## 5. 컴파일과 경고

Tectonic **0.17.0**을 지정 경로에서 실제 실행했고 종료 코드 **0**. Pandoc **3.9**, pypandoc_binary **1.17**, Python **3.10.19**, PyMuPDF **1.28.2**, matplotlib **3.10.7**, numpy **2.2.6**을 사용했다. 명령과 전체 stdout/log는 `README.md`, `compile_stdout.txt`, `shortpaper.log`, `build_validation.json`에 있다.

최종 로그:

- Undefined citations/control sequences, missing symbols: 발견 없음.
- Overfull **hbox: 없음**.
- 마지막 페이지 `balance` 내부의 Overfull **vbox 1.29pt: 1건 남음**. 4쪽 렌더에서 실제 글자 겹침/페이지 경계 초과는 확인되지 않았고, PDF 좌표 검사도 통과했다. 없다고 숨기지 않고 경고로 기록했다.
- Underfull hbox **15건**: 두 단 양끝 정렬·긴 식별자/문헌 줄의 단어 간격 경고. 내용 손실은 발견되지 않았으나 완전히 무경고인 PDF는 아니다.
- `microtype`의 hanging punctuation 때문에 glyph 좌표 검사에는 3 PDF bp의 여백 돌출 허용을 사용했다. 이것은 본문 글꼴·여백 변경이 아니다.
- `chktex`는 이용 가능하지 않아 해당 lint 검사는 미실행. 실제 컴파일·인용·그림·label·좌표·시각 검사로 대체했다.

## 6. 내용 구성과 집중도

제목/초록/서론(관련 연구 통합)/방법/결과/논의와 한계/결론/사사/참고문헌을 갖췄다. 숏페이퍼의 한 주장은 **평가한 CLIP readout의 위치·검출 이득이 관계 기반 후보 선택으로 일관되게 전이되지 않았다**는 관찰이다.

표 1은 위치·검출을, 표 2와 그림 1은 공간 관계 후보 선택을 보여준다. 크기와 with/without은 별도의 큰 기여를 주장하는 대신, 관찰 해석의 경계를 보여주는 진단으로 남겼다. 자세한 문항 집합·12개 scorer·부록·전체 표는 `../manuscript.md`로 연결했다.

## 7. 남은 사항

형식 요구를 충족한 작업본이지 특정 학회 제출본은 아니다. 투고처·저자·소속·익명화·공식 체크리스트는 미정이다. 요청한 사사를 포함했으므로 익명 제출용 판정도 하지 않는다. 신규성 문헌 검토, 사람의 정답·유일성 검증, checkpoint 정확한 식별/학습 중복, 원래 추론 재현, 검출·pointing 신뢰구간, 독립 인간 검토가 미완료다. 이번 요청에 새 실험을 추가하지 않았다.
